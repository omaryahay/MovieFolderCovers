# 🎬 Movie Folder Covers

تطبيق سطح مكتب خفيف لنظام **Windows** يتيح لك تعيين صورة غلاف لأي مجلد فيلم
بحيث تظهر الصورة كأيقونة للمجلد في مستكشف الملفات — دون المساس بأي ملف داخل
مجلدات الشبكة.

![لقطة شاشة](assets/screenshot.png)

---

## ✨ الميزات

- 🖼️ **تعيين غلاف مخصص** لأي مجلد فيلم
- 🤖 **اكتشاف تلقائي** للصور داخل المجلد (poster, cover, folder... إلخ)
- 🔒 **لا كتابة على الشبكة** — يتم تخطي مجلدات الشبكة (UNC و mapped drives) بأمان
- 💾 **حفظ محلي فقط** — كل البيانات في `%LOCALAPPDATA%\MovieFolderCovers`
- 🖱️ **اختيار يدوي** لغلاف مخصص من أي صورة
- ♻️ **إزالة الغلاف** وإعادة المجلد لشكله الطبيعي
- ⚡ **معالجة متعددة** في خيط خلفي دون تجميد الواجهة
- 🌐 **واجهة عربية** بالكامل

---

## 📸 كيف يعمل

1. اختر مجلد فيلم على جهازك
2. اضغط **"تحديث الأغلفة"**
3. سيقوم البرنامج:
   - بقراءة الصور داخل المجلد (أو استخدام الغلاف الذي اخترته يدوياً)
   - توليد أيقونة `.ico` متعددة الأحجام
   - إنشاء `desktop.ini` داخل المجلد لربط الأيقونة به
   - حفظ نسخة من الغلاف في `%LOCALAPPDATA%`

> **ملاحظة**: قد تحتاج لتحديث مستكشف الملفات (`F5`) أو إعادة فتح النافذة
> لرؤية الأيقونة الجديدة.

## 🚀 التثبيت

### المتطلبات

- **Windows 10 / 11**
- **Python 3.9+**

### التثبيت من المستودع

```bash
git clone https://github.com/USERNAME/movie-folder-covers.git
cd movie-folder-covers
pip install -r requirements.txt
python movie_folder_covers.py
```

### تثبيت كأمر

```bash
pip install .
movie-folder-covers
```

---

## 📦 بناء ملف EXE

```bat
pip install pyinstaller
pyinstaller --noconfirm --onefile --windowed ^
    --name "MovieFolderCovers" ^
    --icon assets/app.ico ^
    movie_folder_covers.py
```

سيُنتج الملف في `dist\MovieFolderCovers.exe`.

## 🔒 الخصوصية والأمان

- ✅ **لا اتصال بالإنترنت** — البرنامج لا يرسل أي بيانات
- ✅ **لا تعديل لمجلدات الشبكة** — يتم تخطيها بالكامل

## 🐛 استكشاف الأخطاء

| المشكلة | الحل |
|---------|------|
| الأيقونة لا تظهر بعد التحديث | اضغط `F5` في مستكشف الملفات |
| Windows 11 لا يعرض الأيقونة | تحقق من إعدادات العرض → "إظهار أيقونات المجلدات" |
| "المجلد غير متاح" | تأكد من أن المجلد لم يُحذف أو يُنقل |
| "لا توجد صورة" | أضف صورة داخل المجلد أو استخدم "اختيار غلاف يدوياً" |

## 🛠️ تفاصيل تقنية

- **اللغة**: Python 3.9+
- **المكتبات**: `tkinter` (واجهة), `Pillow` (صور), `ctypes` (Windows API)
- **آلية العمل**: `desktop.ini` + سمات `HIDDEN` و `SYSTEM` عبر `SetFileAttributesW`
- **حجم الأيقونة**: 512×512 الأصل، تُولّد بصيغ 256, 64, 48, 32, 16
